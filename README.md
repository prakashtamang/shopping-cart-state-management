# Shopping Cart State Management

A hands-on React project that demonstrates multiple approaches to managing shopping cart state.

The same shopping cart feature is deliberately implemented in different ways so you can compare how state management evolves as an application becomes more complex.

## Implementations

This project implements the shopping cart four different ways:

1. useState — Simple local component state
2. Context API — Shared state without prop drilling
3. Context + useReducer — Structured and scalable state management
4. Zustand — Lightweight external state management

The goal is not just to build a shopping cart, but to understand the trade-offs, code structure, and use cases of each approach.
