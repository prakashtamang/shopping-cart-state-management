# Shopping Cart — React useState

A simple shopping cart application built with **React useState** and **localStorage**.

This project is **Version One** of a state-management learning series where the same shopping cart feature will later be implemented using:

1. useState
2. Context API
3. Context + useReducer
4. Zustand

The purpose of this project is to understand how local component state works before moving to more advanced state-management solutions.

## Project Overview

This application demonstrates how to manage shopping cart state using React's built-in useState hook.

Users can:

- View products
- Add products to the cart
- Increase product quantity
- Decrease product quantity
- Remove products
- Clear the entire cart
- View total cart items
- View cart subtotal
- Keep cart data after refreshing the browser using localStorage
