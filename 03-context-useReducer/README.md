# Shopping Cart — React Context API + useReducer

A shopping cart application built with **React Context API + useReducer**, useState, and localStorage.

This project is **Version Three** of the same Shopping Cart feature, built to demonstrate how React's Context API and useReducer can work together to manage shared and more complex application state.

The functionality and UI are intentionally kept similar to the previous versions. The main difference is how the cart state is managed.

This project is part of a practical React state-management experiment:

1. Version One: useState + props
2. Version Two: Context API + useState
3. Version Three: Context API + useReducer ← This project
4. Version Four: Zustand

The goal is to understand why and when each state-management approach should be used.
