# Shopping Cart — Zustand

This project is **Version Four** of the same Shopping Cart feature, built using **Zustand** for state management.

The UI and functionality are intentionally kept similar to the previous versions. The main goal is to understand how an external state-management library such as Zustand differs from:

1. useState + Props
2. Context API + useState
3. Context API + useReducer
4. Zustand ← This project

By implementing the same feature multiple ways, you can clearly understand the strengths, limitations, and appropriate use cases of each approach.
